Actions Sidebar Folders

Nest GitHub Actions workflows by / in the name (up to 3 folder levels).

Disabled workflows
Folders

Max folder depth is fixed at 3. Extra / segments stay on the leaf label.

Developer

After editing extension files: open chrome://extensions → click the reload ⟳ on this extension → refresh the Actions tab.

Privacy

This extension only runs on github.com, stores settings in Chrome sync, and does not send data to third parties. Workflow lists are loaded with your existing GitHub session (no personal access token).

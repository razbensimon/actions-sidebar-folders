# Store screenshots

Put Chrome Web Store screenshots here (not included in the extension zip).

Required size: **1280×800** or **640×400** PNG/JPEG.

Suggested filenames:

- `01-sidebar-folders-1280x800.png` — Actions sidebar with nested folders
- `02-options-640x400.png` — Options page (optional)

These files are for dashboard upload only; `pnpm package` does not bundle this folder.
